# Liwan docs

- `rules/` — one file per game: history, board, pieces, full rules, variants, sources (step 2).
- `GDD.md` — game design document (step 3).
- `brand/` — logo, palette, typography, art direction, sound and motion (step 4).
- `ARCHITECTURE.md` — architecture proposal: game modules, online play, content (step 6, awaiting approval).
- `proposals/` — proposals awaiting a decision (new skills, architecture).
